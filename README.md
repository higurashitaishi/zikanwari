# 時間割 (zikanwari)

ブラウザだけで動く時間割アプリ。時間割を入力して表示し、**科目ごとに提出物と提出期限**を管理できます。

ビルド不要・依存ライブラリなし。`index.html` をブラウザで開くだけで動きます。

```bash
git clone https://github.com/higurashitaishi/zikanwari.git
cd zikanwari
open index.html      # Windows なら start index.html / Linux なら xdg-open index.html
```

## 主な機能

| 機能 | 内容 |
| --- | --- |
| 時間割の入力 | 空きマスをクリックして、科目名・教室・担当・メモを登録 |
| 提出物 / 提出期限 | 科目ごとに提出物と期限を登録。完了チェック・削除つき |
| 提出物一覧 | 全科目の提出物を期限の近い順に一覧表示。未提出件数バッジつき |
| 期限の強調 | 期限切れは赤、3日以内は橙。`9/12(土) あと2日` のように残り日数を表示 |
| 「今」表示 | 現在の曜日・時刻に当たるコマにバッジを表示（1分ごとに更新） |
| 時間割の設定 | 曜日（月〜日から自由に選択）、時限数（1〜12）、各時限の開始/終了時刻 |
| 書き出し / 読み込み | JSON でバックアップ・復元。端末間の移行に使えます |
| 印刷 | ボタン類を除いて、時間割と提出物一覧をそのまま印刷 |
| ダークモード | OS の設定に追従 |

## 提出物の考え方

提出物は**コマではなく科目に紐づきます**。

たとえば「数学Ⅱ」が月曜1限と水曜3限にある場合、どちらのコマから開いても同じ提出物リストが表示され、
どちらのコマにも「最も期限が近い未提出の提出物」が出ます。同じ課題を2回登録する必要はありません。

```
┌─────────────┐
│ 数学Ⅱ        │  ← 月曜1限
│ 3-A / 田中   │
│ 📌 レポート   │  ← 科目「数学Ⅱ」の提出物のうち、いちばん期限が近いもの
│    9/12(土)  │
└─────────────┘
```

画面下の「提出物」パネルには全科目ぶんが並びます。並び順は **期限切れ → 期限が近い順 → 期限なし → 完了済み**。
チェックボックスで完了、`×` で削除、「完了も表示」で提出済みも確認できます。

## データの保存先

ブラウザの `localStorage`（キー: `zikanwari.v1`）に保存されます。サーバーへの送信は一切なく、データは端末内にのみ残ります。
別の端末やブラウザに移すときは「書き出し」した JSON を「読み込み」してください。

保存されるデータ構造:

```jsonc
{
  "title": "時間割",
  "days": ["月", "火", "水", "木", "金"],
  "periods": 6,
  "showTimes": true,
  "times": [["08:50", "09:40"], ["09:50", "10:40"]],

  // コマ: "曜日-時限" がキー
  "cells": {
    "月-1": { "subject": "数学Ⅱ", "room": "3-A", "teacher": "田中", "note": "" }
  },

  // 提出物: 科目名がキー
  "subjects": {
    "数学Ⅱ": {
      "assignments": [
        { "id": "…", "title": "課題プリント3", "due": "2026-09-12", "done": false }
      ]
    }
  }
}
```

## 構成

```
zikanwari/
├── index.html   # アプリ本体（HTML + CSS + JavaScript）
└── README.md
```

`index.html` の 1 ファイルのみ。ビルドツール・パッケージマネージャ・外部 CDN は使っていません。
オフラインでもそのまま動きます。

## 動作環境

`<dialog>` 要素と CSS カスタムプロパティを使っているため、モダンブラウザが必要です
（Chrome / Edge 37+、Safari 15.4+、Firefox 98+）。スマートフォンの画面幅にも対応しています。
